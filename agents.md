# Repository Instructions

- This is a single-purpose project for the Eclipse Andalucía 2027 website.
- Keep all work focused on that event and its public website; preserve the Tarragona 2026 edition as a read-only archive.
- GitHub Pages via `make deploy` is the only deployment workflow. Do not add or use OpenAI Sites, Cloudflare hosting, or another deployment provider.
- Use the Makefile entry points for development, testing, builds, and deployment.
- After every coherent change, commit it and push it to `origin/main`, including when working directly on `main`.
- Do not leave completed changes uncommitted or only local.
